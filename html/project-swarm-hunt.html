OVERVIEW

Intelligence emerges together.

A multi-agent pursuit environment exploring how autonomous systems learn to sense, coordinate, and capture as a team.

The interactive graphic above is an illustrative browser preview. The original project uses Python.

IMPLEMENTATION & OUTCOMES
  • Architected a Python multi-agent pursuit environment modeling decentralized swarm intelligence for predator-prey hunting with PettingZoo Parallel API and Gymnasium spaces
  • Designed multi-agent reinforcement learning pipelines with AgileRL MATD3, TorchRL, and VMAS, training predator drones for coordinated pursuit, surrounding, and capture
  • Implemented distance-based combo capture logic, team sensing, and reward shaping to encourage collaborative hunting over naive distance-minimizing pursuit
  • Engineered continuous 2D physics simulation with scripted prey tactics, obstacle hiding, and spatial sensing for emergent swarm hunting behavior
