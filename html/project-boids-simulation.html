OVERVIEW

Simple rules. Collective intelligence.

A flocking simulation built around alignment, cohesion, and separation, with spatial partitioning for efficient neighbor lookup.

The interactive graphic above is an illustrative browser preview. The original project uses Python.

IMPLEMENTATION & OUTCOMES
  • Engineered high-performance flocking simulation in Python and Pygame, implementing Craig Reynolds’ Boids algorithm, achieving 60 FPS performance for 500+ autonomous agents
  • Optimized neighbor-lookup complexity with Uniform Grid Spatial Partitioning, reducing per-frame distance calculations by 90%
  • Implemented custom steering behaviors (alignment, cohesion, separation) and predator avoidance, utilizing Vector math and Euler integration for fluid motion
  • Developed stateless physics engine with clean separation of concerns between data-only objects and pure behavior functions
